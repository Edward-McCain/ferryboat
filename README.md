# Рейс

Лист, по которому я веду ночную смену парома на остров: отход, причал, посадка, отмена.

Данные живут в памяти процесса. Перезапуск возвращает учебное расписание этой ночи. Базы здесь нет.

## Запуск

Из этой папки:

```bash
uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Интерфейс, вторым процессом:

```bash
cd web
npm install
npm run dev
```

Лист открывается на http://127.0.0.1:5173. Описание API — на http://127.0.0.1:8000/docs.

`npm run build` кладёт интерфейс в `web/dist`. Если каталог есть, тот же uvicorn отдаёт его с http://127.0.0.1:8000.
